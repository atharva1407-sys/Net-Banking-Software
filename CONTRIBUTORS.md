## 📝 How Teammates Can Add Themselves (To Appear in GitHub Contributors)

### Method 1: Directly on the GitHub Website (Easiest & Fastest — 1 Minute)
1. Open [`CONTRIBUTORS.md`](https://github.com/atharva1407-sys/Net-Banking-Software/blob/main/CONTRIBUTORS.md) on GitHub.
2. Click the **✏️ (Edit this file)** pencil icon at the top right.
3. Add your name, GitHub handle, role, and contribution focus to the table above.
4. Scroll down to **Commit changes...**
5. Enter a commit message: `docs: add <Your Name> to contributors list`.
6. Select **"Commit directly to the `main` branch"** (or open a pull request).
7. Click **Commit changes**.
8. 🎉 *Within 1–2 minutes, your profile and avatar will appear under the **Contributors** section on the GitHub repository homepage!*

---

### Method 2: Via Local Git Command Line
```bash
# 1. Pull latest changes
git checkout main
git pull origin main

# 2. Open CONTRIBUTORS.md in your editor and add your details to the table

# 3. Commit and push directly with your git identity
git add CONTRIBUTORS.md
git commit -m "docs: add <Your Name> to contributors list"
git push origin main
```
